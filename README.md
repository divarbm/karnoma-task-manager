# کارنوما — اپ مدیریت کارهای روزمره 🗒️

یک اپلیکیشن مدیریت کارها (To-Do) در قالب **یک فایل HTML کاملاً مستقل** — بدون نیاز به نصب، سرور یا اتصال به اینترنت. کافی است فایل را دانلود کنید و در مرورگر باز کنید.

## ✨ امکانات

- 🌗 **پوسته تاریک و روشن** با طراحی مدرن (شیشه‌ای، گرادیان، انیمیشن‌های نرم)
- ➕ **افزودن کار** با اولویت (زیاد / متوسط / کم)، دسته‌بندی (شخصی، کاری، مطالعه، خرید، سلامت) و مهلت (امروز / فردا)
- ✅ **انجام/برگرداندن کار** با انیمیشن، نوار رنگی اولویت و نشان «امروز / فردا» برای مهلت‌ها
- ✏️ **ویرایش درجا** (Enter = ذخیره، Esc = انصراف) و 🗑 **حذف با دکمه بازگردانی (Undo)**
- 🔍 **جستجو** و **فیلتر** (همه / در جریان / تکمیل‌شده) با شمارنده
- 📊 **داشبورد آماری**: تعداد کل، در جریان، تکمیل‌شده و درصد پیشرفت با نوار متحرک
- 📅 **تاریخ شمسی** روز در سربرگ و اعداد فارسی
- 📱 کاملاً **ریسپانسیو** برای موبایل و دسکتاپ، راست‌چین با فونت وزیرمتن

## 🚀 نحوه استفاده

1. فایل `karnoma-task-manager.html` را دانلود کنید (دکمه **Code → Download ZIP** یا لینک مستقیم فایل).
2. فایل را با دوبار کلیک در مرورگر باز کنید — همین!
3. چند کار نمونه برای بار اول داخل اپ هست؛ با حذف یا تکمیل آن‌ها لیست خودتان را بسازید.

## 📱 نسخه اندروید (APK)

نسخه نصبی اندروید از صفحه [Releases](https://github.com/divarbm/karnoma-task-manager/releases) قابل دانلود است:

1. آخرین Release را باز کنید و فایل `karnoma-v1.0.apk` را دانلود کنید.
2. فایل را روی گوشی اجرا کنید؛ چون اپ خارج از گوگل‌پلی است، اندروید یک‌بار اجازه «نصب از منابع ناشناس» می‌خواهد — تأیید کنید.
3. تمام! اپ «کارنوما» با آیکون مخصوص روی گوشی نصب می‌شود.

نسخه APK **کاملاً آفلاین** کار می‌کند، **هیچ مجوزی (permission) نمی‌خواهد** و حجم آن فقط حدود ۳۰۰ کیلوبایت است. فونت فارسی هم داخل خود اپ قرار دارد و نیاز به اینترنت ندارد.

## 🔒 حریم خصوصی

داده‌های شما فقط روی **مرورگر خودتان** (localStorage) ذخیره می‌شوند و هیچ اطلاعاتی به هیچ سروری ارسال نمی‌شود.
